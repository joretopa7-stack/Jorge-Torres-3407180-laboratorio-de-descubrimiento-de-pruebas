# Proyecto Taller Pytest - Módulo II
# Los dos talleres 

Este proyecto contiene la resolución de las actividades de la Sesión 1 del Módulo II sobre fundamentos de Pytest.

## Estructura del Proyecto

- `app/`: Contiene la lógica de producción (`operations.py` e `invoice.py`).
- `tests/`: Contiene los archivos de prueba siguiendo las convenciones de Pytest.
- `laboratorio_descubrimiento_Jorge_Torres.PDF`: Documento con las respuestas teóricas y análisis de los laboratorios.

## Requisitos

- Python 3.12+
- Pytest

## Cómo ejecutar las pruebas

Para ejecutar todas las pruebas de manera detallada:

```bash
python3 -m pytest -v
```
